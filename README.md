# うたログ / Karaoke Performance Log

既存のSites版うたログをReactの画面・記録構造ごとGitHub Pagesに移植した個人用アプリ。

- IndexedDB（専用DB名）に歌唱記録・タグ・採点機を保存。永続化を申請。
- 全件・検索結果のMarkdown／コピー、全件JSONバックアップ、確認付き復元。
- 復元はファイルの内容に置き換え。復元前のデータをダウンロードし、端末にも直前1世代を保持。
- 150件から50件ごとの通知。全件の閲覧用出力とJSON出力の両方で解除。
- 採点機は新規保存時の選択を引き継ぐ。歌唱姿勢は任意、次の記録・過去曲呼び出しには引き継がない。
- 個人データ・Sitesの認証情報を含めない。クラウドへの記録送信なし。
- ホーム画面追加、オフライン起動、noindex対応。noindexはアクセス制限ではない。

## 開発

Node.js 22以上。`npm ci` → `npm test` → `npm run build`。
`dist`が公開対象。GitHub ActionsでビルドしPagesに公開する。

## 移行

移行用JSONを「設定・データ管理」から選択し、件数を確認して復元。
クラウドのスナップショットに含まれないスマホ内の最新記録は別途照合が必要。
復元後に表示する件数・全項目照合結果を確認し、元のSitesはそのまま保持する。
JSONファイルはこの公開リポジトリにアップロードしない。

## バックアップ通知

記録数の最高到達件数を保持し、削除と再追加で同じ節目を繰り返さない。
検索結果のみの出力は全件が含まれる場合に限って通知解除に数える。
ダウンロード開始後のファイル保存・キャンセルはブラウザから検知できないため、利用者はダウンロード先を確認する。

## 更新

アプリを更新する際は`public/sw.js`のキャッシュバージョンも変更する。
起動中の全タブを閉じて再度開くと待機中の更新が有効になる。
